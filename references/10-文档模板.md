## 质量门禁与用户批准
- 当前版本开工：未确认 / 已确认；已确认后，当前 Agent 与可控子 Agent 连续执行到版本验收，不逐步确认。
- 再次确认触发：仅高风险操作 / 边界或验收不清 / 执行中需用户决定的问题；普通步骤、卡片、波次、测试和可控子 Agent 派发不触发。
- 外部接手：未发生 / 待用户操作 / 已确认；仅外部不可控 AI、用户复制交接包或登录授权时请求该次确认。
- 开发前开源参考与复用门禁：未开始 / R1 已跳过并记录理由 / 搜索中 / 已完成 / unknown 待补查
- 合法合规门禁：未开始 / 已通过 / unknown 待补查 / 不通过；权利来源、授权范围、许可证/NOTICE、数据依据、隐私与适用法律/行业规则已检查
- 评估文档：`[PROJECT_ROOT]\docs\02-开源参考与复用评估.md`
- 采用决定：直接采用 / 组合组件 / Fork 改造 / 只参考架构或交互 / 做 POC / 完全自研
## 成本/超时/失败接手
```

## 文档质量

每份重大文档必须：具体、准确、结构清楚、引用绝对路径、区分事实/建议/未知、关联 ID、能让另一个 AI 无聊天上下文继续、包含完成证据和下一动作。

不复制同一事实到多份文档：权威事实只写一处，其他文档用链接和 ID 引用。变更先更新权威来源，再更新索引/状态。
